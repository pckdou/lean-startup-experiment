# Lean Startup Experiment (13주차)

AI 학습 플래너의 온보딩 단축 가설을 Feature Flag A/B 테스트로 검증한 실험 저장소.

## 구조
- `app/` MVP (Flask) + Feature Flag
- `personas/` LLM 페르소나 10명 정의, 피드백 생성, 트래픽 시뮬레이션
- `data/feedback/` 페르소나 피드백 JSON / `data/events/` A/B 이벤트 로그
- `analysis/` 지표 계산 / `docs/` 가설·설계·리포트·결정 기록
- `.github/` Issue 템플릿, 주간 리포트 Actions
