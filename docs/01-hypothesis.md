# 가설 (서비스 아이디어에 맞게 수정하세요)

- 서비스: AI 학습 플래너 — 시험 일정을 입력하면 AI가 학습 계획을 자동 생성
- 대상 고객: 시험기간 대학생
- 문제: 학습 계획을 세우다 포기하거나, 가입 절차가 길어 이탈한다
- 가설: 온보딩을 5단계 → 2단계로 줄이면 가입 완료율이 15%p 이상 오른다
- 핵심 지표(North Star): 가입 완료율 = signup_completed / visit
- 보조 지표: 첫 기능 사용률(feature_used), 이탈률
- 성공 기준: B안 완료율이 A안보다 +15%p 이상, 각 그룹 n≥30
